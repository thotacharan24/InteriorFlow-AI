# Five-Minute Demonstration

1. Open http://127.0.0.1:5000 and explain that the prototype uses synthetic data.
2. Show dashboard metrics calculated from SQLite records.
3. Submit a dummy 3BHK enquiry with consent. Expected: 100/100 in the demo case, Hot classification and four follow-up sequences.
4. Open Leads and demonstrate search, classification and CSV export.
5. Run AI Marketing Studio. Expected: template fallback or Gemini live mode clearly identified.
6. Ask the customer assistant about services or modular kitchens. Unknown company policies should remain unconfirmed.
7. Open a consultation and select a duplicate time to demonstrate conflict detection.
8. Open Projects and run the deadline monitor. Overdue project/payment alerts appear in actual database state.
9. Open n8n at http://localhost:5678, import automation/lead-capture.json or monitor.json, and execute against the running Flask server.
10. Explain that no external messages, real appointments or payments are sent.
